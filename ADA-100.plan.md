# ADA-100 archive cleanup plan

1. Prove the existing cascade only archives descendant rows while runtime cleanup
   remains parent-scoped.
2. Move archive cleanup out of the WebSocket archive handler into a reactor keyed
   on each committed `thread.archived` event.
3. For each archived thread event, dispatch the normal `thread.session.stop`
   command for that thread when it has a live projected session, and close that
   thread's terminals without deleting history.
4. Keep late provider turn-start work from recreating sessions for archived
   threads, and leave unarchive as a pure projection restore.
5. Verify with focused tests, an ephemeral server regression, `vp run typecheck`,
   and `vp check`.
